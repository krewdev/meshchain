Hybrid vault deposit

Deposit Solana devnet SOL bound to your mesh short id. The public seed relayer mints tMESH (minus fee). Cash-out later needs mesh burn + attestors.

1. Register on mesh first (or deposits stay deferred): 
mesh join-public
mesh new-wallet --name me.json --publish
mesh faucet-drip --wallet me.json
mesh address --wallet me.json   # copy the 16-char hex id
  1. Paste your 16-char hex short id (from mesh address).
  2. Fund a Solana devnet wallet, then deposit with CLI (or Anchor script).
  3. Watch mint status below — balance should jump after the relayer mints.
